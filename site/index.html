How it works

One createServer() call builds the MCP server and its nine tools. Three runtimes wrap that same server in a different transport, so a tool gives the same answer wherever it runs.

createServer() 9 tools
  • ab_test_evaluate
  • ab_test_plan
  • email_test_analyze
  • budget_simulate
  • budget_optimize
  • store_sales
  • customer_rfm
  • lead_funnel
  • attribution_compare

  1. In your browser

    The playground on this page imports createServer() and connects to it over an in-memory transport. The call never leaves the tab. 

    {"jsonrpc": "2.0", "id": 2,
 "method": "tools/call",
 "params": {
  "name": "ab_test_plan",
  "arguments": {
   "baseline_rate": 0.03,
   "mde_relative": 0.2,
   "daily_visitors": 2000}}}

  2. On a Cloudflare Worker

    The Worker builds a fresh server for every request and answers Streamable HTTP at /mcp. That URL is what you paste into Claude as a custom connector. 

    {"jsonrpc": "2.0", "id": 2,
 "method": "tools/call",
 "params": {
  "name": "budget_optimize",
  "arguments": {}}}

  3. On your machine

    npm run start:stdio runs the same server over stdin and stdout, one JSON-RPC message per line, so Claude Desktop can start it as a local command. 

    {"jsonrpc": "2.0", "id": 2,
 "method": "tools/call",
 "params": {
  "name": "store_sales",
  "arguments": {
   "group_by": "category"}}}
